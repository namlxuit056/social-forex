# Security Policy

Please **do not** open a public issue for security vulnerabilities.

Report them privately through [GitHub Security Advisories](https://github.com/namlxuit056/social-forex/security/advisories/new). Include steps to reproduce and the impact you observed. You will get a reply within a few days, and a fix will be released before details are made public.

Never commit real credentials — use `.env` (gitignored) and keep `.env.example` free of values.
